# Model and data

## Data

The classifier was trained on a light microscopy image of a mouse kidney section that was treated with the drug AsiDNA. 
In the image, cells undergoing division are specifically labeled with 5-ethynyl-2'-deoxyuridine (EdU).

## Model
This model was trained using the Trainable WEKA Segmentation plugin in Fiji for the semantic segmentation of mouse 
kidney tissue. 
The underlying principle of this method is to train a machine learning classifier not on raw pixel values, 
but on a set of "features" calculated for each pixel using a series of image filters. For this specific model, 
a FastRandomForest classifier was trained to recognize four distinct classes: dividing nuclei, non-dividing nuclei, 
other tissue, and background. 
The features used for this classification were generated by applying Hessian, Sobel filter, Difference of Gaussians, 
and Membrane Projections filters to the source image.


# Prediction
## Expected image
An RGB image of a mouse kidney section prepared and stained in a manner similar to the training image.

## Result
The final output is a **semantic mask**, where each class is represented by a unique pixel value.
